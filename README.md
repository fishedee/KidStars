# 我的世界任务站

基于 React 19、TypeScript 和 Rsbuild 的儿童学习任务应用，覆盖小学一年级到六年级的语文、数学和英语学习，并结合阅读、运动、健康打卡、装扮与奖励兑换。

## 主要功能

- 全局选择一年级到六年级，支持上册、下册切换；所有年级立即开放，默认进入三年级。
- 语文按人教版方向组织课文、生字和古诗，支持拼音显隐、发音、笔顺演示与书写练习。
- 数学按年级提供课程目录、分级题目、普通/限时模式、连击反馈、提示与答案讲解。
- 英语按年级和学期提供单词、句型、听读及闯关练习。
- 每日混合挑战串联语文、数学和英语题目，并提供即时判定和进度反馈。
- 每个年级独立保存学习进度；阅读、健康、星光币、书架、装扮和奖励数据全局共享。
- 连续学习天数、成就徽章和首页课程进度帮助跟踪学习状态。
- 适配桌面和移动设备，并支持减少动态效果的系统偏好。

## 开发

```bash
npm install
npm run dev
```

开发服务器默认运行在 `http://localhost:3000`。

## 验证

```bash
npm run test
npx tsc --noEmit
npm run build
```

## 本地数据

应用使用浏览器 `localStorage` 保存进度：

- `learning-quest:v3:daily:<YYYY-MM-DD>`：当日共享任务和各年级独立学习进度。
- `learning-quest:v3:profile`：当前年级/学期、星光币、连续学习、成就、书架、装扮和奖励记录。

首次读取旧版 `learning-quest:v2:*` 数据时，原学习进度会迁移到三年级；星光币、书架、装扮、奖励和英语阅读数据会继续保留。更早的 `girldaily_*` 数据不会被读取或删除。
